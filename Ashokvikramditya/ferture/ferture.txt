Here are some of Git's most useful and powerful features, categorized by how they help you manage code:

1. Safety & History Management
git reflog (The Safety Net): Records every single change to your repository’s reference heads (like HEAD or branches), even commits that were deleted or lost during a bad rebase. It allows you to recover almost anything.

git bisect (Automated Bug Hunting): Performs a binary search through your commit history to quickly locate which exact commit introduced a bug.

git stash (Temporary Workspaces): Temporarily shelves uncommitted changes so you can switch branches or pull updates without committing incomplete work.

2. Branching & Merging Strategies
Lightweight Branching: Branches in Git are simple 41-byte pointers to commits, making branch creation, switching, and deletion near-instantaneous.

git rebase vs git merge: Gives you control over how history is presented—either creating a linear, clean history via rebasing or preserving exact history with explicit merge commits.

Interactive Rebase (git rebase -i): Lets you clean up commit history before sharing code by combining ("squashing"), reordering, or rewording past commits.

3. Granular Control & Utilities
git add -p (Interactive Staging): Allows you to stage specific lines or hunks of code rather than an entire file, making it easy to create focused, logical commits.

git cherry-pick: Pulls a single commit from another branch and applies it directly to your current working branch.

git worktree: Allows you to check out multiple branches simultaneously into separate directories on your local machine without needing multiple clones.
